
# Proyecto 2 BECALOS - Traxion (Grupo B)

## Que contiene este repositorio

Este repositorio es una página e-commerce de una tienda de música llamada: MICHI MÚSICO, ejemplificando todo lo aprendido en el modulo 2, como propiedades básicas de CSS, Herencia en CSS, FLexbox, Position, Estilos responsivos, Grid.   Contiene:

- `index.html` como página principal. 
- `Style.css` como estilos globales con diseño responsivo.
- Archivos de imágenes
